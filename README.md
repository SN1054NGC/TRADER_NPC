# TRADER_NPC — торговец для DayZ (сборка без коинов)

Реворк торговца для **DayZ 1.29** на базе **Dr. Jones Trader** (см. `CREDITS.md`):
система торговцев, валюты и интерфейс взяты оттуда, поверх — авто-цены, стаки,
серверная оценка предметов, рейтинг выживания, сейф-зона и торговля машинами.

## Возможности

- авто-цены из `db/types.xml` (категории, редкость, калибр, ёмкость, броня/тепло/камуфляж);
- продажа стаками с ползунком количества; магазины целиком, патроны поштучно;
- серверная оценка предметов: износ, стадии еды, жидкости, бонус за вложенные обвесы
  и патроны, утилизация испорченного;
- рейтинг выживания (время, путь, убитые заражённые) → скидка до 20 %;
- сейф-зона торговца: торговля из любой её точки, звук купюр для всех рядом;
- **машины**: покупка у торговца машин с запчастями, полным баком и заряженным АКБ,
  замок на ID покупателя (без ключа-предмета), выдача доступа другим игрокам,
  продажа машины обратно с ценой по состоянию;
- озвучка торговца, ответы ИИ в чате, выплата за убийство заражённого;
- всё включается/выключается в `TraderNpcVariables.txt` (`<VoiceEnabled>`, `<AutoPrices>`,
  `<AutoPricesApply>`, `<SellAnywhere>` и т. д.);
- ванильный стиль интерфейса и русская локализация.

## Требования

- DayZ 1.29 (сервер + клиент);
- [PBO Manager](https://pbo.tools) для сборки PBO (AddonBuilder не используется);
- остальные моды вашей сборки — на ваш риск.

## Установка

1. Скопировать `addons/TRADER_NPC.pbo` (или папку `addons/TRADER_NPC/` целиком) в
   `<DayZ Server>/@TRADER_NPC/addons/`.
2. Запускать сервер с `-mod=...;@TRADER_NPC`. Для loose-версии (исходники вместо PBO)
   нужен `-filePatching`.
3. **Профильные файлы**: содержимое `Profiles/Trader_NPC_Prof/` скопировать в
   `<Профиль>/Trader_NPC_Prof/` (мод читает `$profile:Trader_NPC_Prof/*.txt`), затем
   переименовать `*.example.txt` в рабочие имена `.txt` (без суффикса `example`).
4. Клиенту достаточно того же мода в `-mod=`.

## Команды в чате

| Команда | Действие |
|---|---|
| `!кар add <ник>` | дать доступ к своей машине |
| `!кар del <ник>` | отозвать доступ |
| `!кар list` | список допущенных |
| `!кар lock` / `!кар unlock` | запереть / отпереть машину |
| `!кар service` | заправить и зарядить АКБ своей машины |
| `!кар sell` | продать машину торговцу (цена зависит от состояния) |
| `!кар who` | кто владелец машины |
| `!вопрос` | вопрос ИИ-торговцу |

## Профильные файлы

В репозитории только примеры с плейсхолдерами: живые конфиги и UID администраторов
исключены через `.gitignore`.

| Файл | Назначение |
|---|---|
| `TraderNpcVariables.example.txt` | основные настройки (таймеры, рейтинг, авто-цены, звук, выключатели) |
| `TraderNpcObjects.example.txt` | торговцы: маркеры, позиции, сейф-зоны, точки выезда машин, объекты |
| `TraderNpcConfig.example.txt` | ассортимент и цены: `Класс, Кол-во, Покупка, Продажа, [патрон]` |
| `TraderNpcConfig_auto_only.example.txt` | вариант конфига, где ассортимент целиком из авто-цен |
| `TraderNpcAdmins.example.txt` | UID администраторов торговца |

Поле «Кол-во»: `*` — максимум, `M` — магазин, `W` — оружие, `S` — стейк,
`VNK` — машина без ключа, `V` — машина с ключом. Продажа `-1` или `nosell` — не скупает.

## Сборка, деплой и проверка

| Скрипт | Назначение |
|---|---|
| `build_pbo.ps1` | сборка `TRADER_NPC.pbo` через PBOConsole |
| `deploy_server.ps1` | раскладка loose-копии скриптов на сервер |
| `check_compile.ps1` | запуск сервера, проверка компиляции модулей и загрузки торговцев |
| `_build/deploy_when_free.ps1` | ждёт закрытия DayZ, собирает, раскладывает, проверяет |
| `_build/audit_assortment.ps1` | сверка ассортимента торговцев с оборудованием мира (`types.xml`) |
| `_build/restore_working.ps1` | откат к тегу рабочей сборки |

Пути в скриптах заданы параметрами с разумными значениями по умолчанию
(`-Srv`, `-PboConsole`, `-Mods`, `-ServerMods`) и переопределяются при запуске.

## Инструменты интерфейса

- `layout_viewer.html` — просмотр ванильных и модовых `.layout` (собирается `_build/refresh_viewer.js`);
- `sell_designer.html` — конструктор окна продажи;
- `LAYOUT_UI_GUIDE.md` — правила разметки интерфейса DayZ.

## Документация

- `CONFIG_AUTO.md` — авто-цены из `types.xml`;
- `SPLIT_SERVER_CLIENT.md` — что уходит в серверную часть, а что в клиентскую;
- `LAYOUT_UI_GUIDE.md` — `.layout`: виджеты, стили, привязки;
- `CREDITS.md` — авторы и происхождение кода.
