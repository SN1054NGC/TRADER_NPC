# TRADER_NPC — торговец для DayZ (сборка без коинов)

Реворк торговца для **DayZ 1.29**: авто-цены из `types.xml`, продажа стаками с ползунком, серверная
оценка предметов, рейтинг выживания со скидкой, сейф-зона, ванильный интерфейс, русская локализация.

## Требования
- DayZ 1.29 (сервер + клиент).
- [PBO Manager](https://pbo.tools) (сборка PBO; AddonBuilder не используется).
- Другие моды из вашей сборки — на ваш риск (см. «Совместимость»).

## Установка
1. Скопировать `addons/sps_client_bot.pbo` (или папку `addons/sps_client_bot/` целиком) в
   `<DayZ Server>/@sps_client_bot/addons/`.
2. Запускать сервер с `-mod=...;@sps_client_bot`. Для loose-версии (исходники вместо PBO) нужен `-filePatching`.
3. **Профильные файлы**: скопировать содержимое `Profiles/Trader/` в `<Профиль>/Trader/`
   (мод читает `$profile:Trader/*.txt`).
4. Клиенту достаточно того же мода в `-mod=`.

## Профильные файлы (`Profiles/Trader/`)
| Файл | Назначение |
|---|---|
| `TraderVariables.txt` | основные настройки (таймеры, рейтинг, скидка, авто-цены, звук) |
| `TraderObjects.txt` | торговцы: маркеры, позиции, сейф-зоны, объекты, одежда |
| `TraderConfig.txt` | ассортимент и цены (строки `Класс, Кол-во, Покупка, Продажа, [патрон]`) |
| `TraderConfig_auto.txt` | авто-цены, генерируется модом из `db/types.xml` |
| `TraderConfig_Vehicles.txt`, `TraderConfig_Boats.txt` | отдельные категории |
| `TraderVehicleParts.txt`, `TraderVehicleParts_Boats.txt` | запчасти к транспорту |
| `TraderAdmins.txt` | UID администраторов торговца |

> ⚠️ `TraderAdmins.txt` содержит UID — замените на свои перед публикацией конфигов.

## Сборка из исходников
    .\build_pbo.ps1        # собрать PBO (PBO Manager) и положить рядом с addon
    .\deploy_server.ps1    # разложить исходники/PBO в папку сервера
    .\check_compile.ps1    # проверка: структура PBO, компиляция, загрузка конфига, торговцы

## Возможности
- **Авто-цены** из `types.xml`: категория × спрос × редкость × калибр × ёмкость × броня/тепло/камуфляж/размер.
- **Продажа стаками**: ползунок количества, магазины продаются целиком, пачки патронов — поштучно.
- **Оценка на сервере**: износ, стадии еды (сырое/горелое/гнилое), жидкости, бонус за вложенные патроны/обвесы.
- **Рейтинг выживания → скидка до 20 %**: время + пройденный путь + убитые заражённые (настраивается).
- **Награда за заражённого**: сумма = цена 1 шт. самого слабого патрона (ключ `<KillReward>`).
- **Торговля из сейф-зоны** (без подхода вплотную), проверки на сервере.
- **Звук купюр** для всех рядом (ванильные сэмплы), ванильный UI, локализация RU.

## Инструменты (папка `_build/`)
Валидатор layout, линтер торгового конфига, генератор/симулятор цен, просмотрщик layout
(`layout_viewer.html`). Запуск: `node _build/<скрипт>.js`.
